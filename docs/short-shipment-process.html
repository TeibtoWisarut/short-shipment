Short Shipment — Update Qty Cut Short

เครื่องมือปรับปรุงจำนวนสินค้าที่ขาดส่ง (short shipment) บน Shipping Advice แล้ว cascade ลงไปมาวฏื่น เกิดได้ทั้ง Phase A (ก่อน Gen IF รถยังไม่ออกจากโรงงาน) และ Phase B (หลังรถออกแล้ว มีปัญหาระหว่างทาง) จุด focal คือ step ที่ "Start Process" เพราะเป็นจุดที่ cascade เขียนลง 5 record พร้อมกันจริง

คลิกอกฮือตัวเลขขั้นตอนเพื่อไฬน · สื่อขยาย +/- เพื่อซูม แล้วคลิกลากบนดิาแกรมเพื่อเลื่อนดู

100%

3 ระดับของ SHORT

Qty / Line / Container

  • Qty-level: ลดบางส่วนใน 1 แถว ไม่ถึง 0
  • Line-level: 1 item ในตู้นั้น = 0 ทั้งหมด (ใบ Short ทั้งแถว)
  • Container-level: ทุก item ในตู้นั้น = 0 พร้อมกัน ศ;ติก Heavy Container

PHASE A vs PHASE B

ไม่ Exclusive กัน

  • Phase A (ก่อน Gen IF): อ่านค่าจาก Wave Quantity
  • Phase B (หลัง Gen IF): อ่านค่าจาก Qty Shipped
  • Container เดียว Short ได้ทั้ง 2 Phase คนละรอบ

FOCAL STEP

Start Process (step 5)

  • เขียน 5 record: SA, Plan Load, TO, Wave, IF/IR
  • Retry 3 ครั้งเมื่อเจอ RCRD_HAS_BEEN_CHANGED
  • Qty Old ประเทศแรกที่ Short เกิด ไม่เขียนทับซำ
